## Overview

Prisma Cloud is Palo Alto Networks' flagship cloud-native security platform. As Design Lead, I owned the end-to-end design of the platform's unified design system—spanning tokens, components, patterns, and documentation.

## Challenge

Six product teams were building independently, creating an inconsistent user experience and significant design debt. Engineers spent weeks re-implementing common UI patterns. Designers had no single source of truth.

## Process

I started with a comprehensive audit across all six surfaces, mapping component usage and identifying duplication. From there I built a token architecture, component library, and governance model that let teams move fast without breaking things.

## Outcome

Reduced design-to-dev handoff time by 60%. Shipped 120+ documented components. Established quarterly design system reviews that kept the library aligned with product evolution.
