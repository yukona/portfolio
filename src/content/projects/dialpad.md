## Overview

Dialpad (formerly UberConference) is a cloud communications platform for teams. I led product design across the web app, focusing on the call flow and team management surfaces.

## Challenge

The original interface exposed too much telephony infrastructure to end users. Non-technical users were confused; power users couldn't find advanced features quickly.

## Process

Starting with user interviews and session recordings, I mapped the core use cases and built a simplified mental model. I ran weekly prototype tests with real users to validate decisions before building.

## Outcome

Launched to 100k+ users with a measurably lower support ticket volume. The simplified call flow became the foundation for Dialpad's subsequent mobile apps.
